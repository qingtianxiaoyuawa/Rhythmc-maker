# RhythMC Maker ImGui UI 不显示修复记录 - 2026-09-27

## 现象与判断
- 用户截图显示 Minecraft 世界背景被模糊处理，但迁移后的 UI 面板完全不可见。
- 旧版 1.1.10 依赖 owo-lib 的 `BaseOwoScreen`，由 owo adapter 管理 Screen 生命周期和 GUI 状态；当前版本改为 ImGui 后，组件树已存在，但 ImGui OpenGL 绘制直接接入 Minecraft 屏幕渲染链。
- 本轮重点修复 ImGui 绘制边界，而不是恢复 owo 前置。

## 修改文件
- `src/main/java/cn/frkovo/rhythmcmaker/client/ImGuiRuntime.java`
  - 移除 Docking host 初始化和每帧 dockspace 创建，改为单一固定 ImGui 窗口，避免 docking 宿主覆盖或吞掉页面内容。
  - `ImGuiImplGl3` 改用自身默认 GLSL 版本初始化，避免强制 `#version 150` 与当前 Minecraft OpenGL 上下文产生兼容问题。
  - 在提交 draw data 前使用当前 LWJGL 的 `GL11` API 显式设置 blend、blend func、depth、cull、scissor 状态，确保 ImGui 绘制不被 Minecraft/Sodium 的残留状态裁剪或遮挡。
- `src/main/java/io/wispforest/owo/ui/base/BaseOwoScreen.java`
  - 强制主 ImGui 窗口背景 alpha 为 1，保证页面面板不透明显示。
  - 保留现有页面组件树、按钮、文本框、下拉框、文件选择、谱面/场景/特效编辑业务回调。
