# RhythMC Maker Dear ImGui UI 迁移记录

- 时间：2026-09-26 +08:00
- 任务：接入 `ocornut/imgui` 对应的 Java/LWJGL 绑定，重构现有 UI 并移除 owo-lib 前置，保持制谱、导入导出、场景与特效编辑的业务逻辑。

## 实现

1. Dear ImGui 本体是 C++ 库，Fabric Java 工程通过其 Java/LWJGL 绑定 `imgui-java 1.92.7.1` 接入：`imgui-java-binding`、`imgui-java-lwjgl3` 和 Windows 原生库均以 Jar-in-Jar 方式打入最终 mod。
2. 新增 `ImGuiRuntime`：创建 ImGui context、复用 Minecraft GLFW 窗口且不接管其回调、执行 OpenGL3 draw-data 渲染，并使用 Windows `simhei.ttf` 加载简体中文字形；字体缺失时回退默认字体。
3. 原有 16 个功能页面统一继承 `RhythmcScreen` 的 Dear ImGui 渲染路径；项目内兼容组件层保留原有屏幕的表单/按钮树和业务回调，从而不改变谱面保存、文件选择、场景确认、播放设置等逻辑。
4. 特效编辑器改为同一 Dear ImGui 页面：保留模板插入、事件选择、拍点/时长/文本/颜色/数量编辑、关键帧、新增删除和保存操作，并改善说明文字和三栏布局。
5. 移除了外部 `owo-lib` Gradle 依赖、Wisp Forest 仓库和两个 `fabric.mod.json` 中的 owo 前置声明。项目内兼容包只用于将现有页面逻辑过渡到 Dear ImGui，不依赖任何外部 owo JAR。
6. 版本由 `1.3.8` 更新为 `1.3.9`。
