# RhythMC Maker 2.3.2 - 音符渲染、交互与编辑坐标修复

## 修复内容

- 五种音符物品模型切换为 Minecraft 1.21.11 有效的原版方块模型引用，修复物品栏黑紫缺失纹理。
- 普通音符放置时播放对应音效并触发手臂挥动；Tap、Look、Hold、Dodge 分别使用 TNT、侦测器、钻石块、红石块放置音效；Hold 组使用 note block pling。
- 编辑器轨道清理完成后重建 Hold 组视觉补足实体；清理完成检测移到整批任务处理之后，避免任务重排时误判完成，并按轨道与组 ID 唯一识别。
- 展示音符设置为 1×1 显示范围，右键解析使用 Minecraft 展示实体可见边界，避免可点击区域小于模型。
- 音符菜单的 X/Y 均保留相对编辑坐标；服务端统一转换相对 Y 与谱面绝对 Y。改 Beat 的独立命令仍只改时间轴，不修改 Y。新增坐标往返回归断言。
- 版本由 2.3.1 更新至 2.3.2。
