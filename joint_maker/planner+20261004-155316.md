# 本轮规划记录

## 用户问题
总结 RhythMC 3.0 全部特效的作用、可填写字段、字段格式和单位。

## 核对范围
- RhythMC 3.0/Reborn 源码：`analysis/RhythMC-Reborn-master/src/main/java/cn/frkovo/rhythmcv2/Game/Effects/EffectFactory.java`、各 `EffectImpl`、`EffectType.java`、`EffectDeserializer.java`。
- Maker 当前编辑器注册表：`src/main/java/cn/frkovo/rhythmcmaker/common/effect/EffectTypeRegistry.java`。

## 关键格式结论
- Reborn 3.0 官方特效对象使用：`effectType`、`beat`、`properties`。
- `beat` 为 JSON number，对应谱面 Beat。
- Maker 当前解析兼容 `eventType`，并将 `type` 作为回退字段；导出时应优先保持 RhythMC 3.0 的 `eventType`/现有项目约定，实际实现需统一字段名。
- 官方 `properties` 内的字段以 EffectFactory 的 `get...` 调用为准；Maker 注册表不是完整协议，有些字段名只是 UI 草稿定义。

## 官方特效清单
HOLOGRAM、REMOVE_HOLOGRAM、TITLE、FIREWORK、TIME、EFFECT、CLEAR_EFFECT、WEATHER、ARENA、TEXT_DISPLAY、TEXT_DISPLAY_EFFECT、TEXT_DISPLAY_SYNC_TRACK、TEXT_DISPLAY_DESYNC_TRACK、HIDE_NOTES、GLOW_COLOR、MESSAGE、TEXT_DISPLAY_REMOVE。

## 官方字段摘要
- HOLOGRAM：`location:[x,y,z]`，`contents:string[]`，可选 `id:string`、`duration:long`；位置为相对游戏中心偏移，duration 毫秒。
- REMOVE_HOLOGRAM：`id:string`。
- TITLE：`title:string`、`subtitle:string`、`fadeIn:int`、`stay:int`、`fadeOut:int`；源码传入 Bukkit Title API 的 Duration.ofMillis，因此单位毫秒。
- FIREWORK：`locations:[[x,y,z],...]`、`colors:[[r,g,b],...]`、`fadeColors:[[r,g,b],...]`、`type:string`（BALL/LARGE_BALL/STAR/BURST/CREEPER）、`flicker:boolean`、`trail:boolean`；位置相对游戏中心，颜色每个通道 0–255。
- TIME：`time:long`、可选 `duration:long`；时间为 Minecraft 世界时间刻度，duration 毫秒。
- EFFECT：`effectId:int`、`amplifier:int`、可选 `duration:long`；effectId 为 Bukkit PotionEffectType 数字 ID，duration 毫秒。
- CLEAR_EFFECT：可选 `effects:int[]`；缺省或空 properties 清除全部药水效果，提供数组时仅清除指定数字 ID。
- WEATHER：`weather:string`，源码文档值为 `DOWNFALL` 或 `CLEAR`。
- ARENA：`arena:string`，竞技场名称。
- HIDE_NOTES：可选 `noteTypes:string[]`（TAP/LOOK/HOLD/DODGE）和 `tracks:int[]`；空数组用于显示全部，具体运行时应以源码为准。
- GLOW_COLOR：`color:string`，源码示例使用 Minecraft/Bukkit ChatColor 名称，如 `RED`。
- MESSAGE：`contents:string[]`。
- TEXT_DISPLAY：`position:[x,y,z]`、`rotation:[x,y,z]`、`scale:[x,y,z]`、`text:string`、`id:string`。
- TEXT_DISPLAY_EFFECT：必填 `id:string`、`type:string`；type=TEXT 时 `text:string`；SHADOW 时 `shadowed:boolean`；OPACITY 时 `targetOpacity:number`（0–255）；BACKGROUND_COLOR 时 `color:[r,g,b,a]`；LINEAR_TRANSFORMATION 时 `position`、`rotation`、`scale`；GLOWING 无额外字段。
- TEXT_DISPLAY_SYNC_TRACK：`id:string`、`track:int`、可选 `duration:long`；duration 毫秒，持续读取 Track 位移/旋转/缩放。
- TEXT_DISPLAY_DESYNC_TRACK：`id:string`。
- TEXT_DISPLAY_REMOVE：`id:string`。

## Maker 当前注册表差异
- Maker 注册了 `ACTIONBAR`、`CHANGE_ARENA`，但它们不在本地 Reborn `EffectType` 枚举中，不能未经适配直接视作 3.0 官方特效。
- Maker UI 的 `EFFECT` 字段显示为 `effect`，而官方 `EffectFactory` 读取 `effectId`；应在导出适配层转换。
- Maker UI 的 FIREWORK 字段显示为 `x/y/z/color/count`，而官方格式需要 `locations/colors/fadeColors/type/flicker/trail`；不能直接照 UI 草稿生成官方对象。
- Maker UI 的 TEXT_DISPLAY 系列使用扁平的 `x/y/z/scale/opacity` 草稿字段，而官方 TextDisplay 使用数组和 `id`；需要转换层。
- Maker 当前播放代理对多个 TextDisplay/Hologram 类型只做了简化处理，不能等同于 Reborn 服务端的完整显示行为。
