# 3.0 导入 BPM 与 Offset 处理修正

- 时间：2026-09-25 16:15:00 +08:00
- 修正：3.0 谱面导入时不测量 BPM、Offset；以 `.rmcc` 内的谱面数据为准。

## 数据来源

导入难度文件时读取：

- `meta.bpms[]`：BPM 变化点，包含 `beat` 与 `bpm`；
- `meta.offset`：RhythMC 谱面偏移，单位毫秒；
- `meta.initialArena`：初始场景引用；
- `tracks[].speedEvents`：流速事件；
- `effects[]`：特效和场景切换事件。

不能使用导入歌曲文件重新测量的结果覆盖上述字段。

## 导入界面调整

上传歌曲文件后只做：

- 绑定音频；
- 显示文件名、时长和格式；
- 检查音频文件是否可读；
- 建立歌曲资源映射。

不自动打开 BPM/Offset 测量页面，不自动修改谱面数据。

可选提供“重新测量”按钮，但必须是用户主动操作，并明确提示：

```text
重新测量只用于参考，不会自动覆盖导入谱面的 BPM、Offset 或 BPM 变化。
如需使用测量结果，请手动确认并另存为新版本。
```

## 状态显示

导入主页显示：

```text
BPM：读取自 world.rmcc
Offset：读取自 world.rmcc
BPM 变化：已读取 N 个节点
音频：已绑定 song.mp3
```

如果导入多个难度，应分别显示每个难度的 `offset`、BPM 节点数量和首个 BPM；不能假设所有难度共享同一套 timing 数据。

## 校验规则

- `meta.bpms` 不存在或为空：标记为谱面 timing 缺失；
- BPM 小于等于 0、beat 非有限数值：导入失败或要求修复；
- `meta.offset` 缺失：按 0 处理并显示警告，不能静默伪造测量值；
- 读取到的 BPM/Offset 原样保存；
- 如果转换成当前 Maker 简化模型会丢失 BPM 变化点，应保留原始 `.rmcc` 或扩展内部模型。

## 编辑与导出原则

- 导入时不重新测量、不替换 `.rmcc` 中的 timing；
- 用户手动修改 BPM 或 Offset 后，标记谱面为已修改；
- 导出时使用用户当前确认的数据；
- 仅替换歌曲文件不会自动改变 BPM、Offset 和 beat 位置；
- 如果音频时长与 `manifest.yml` 或 `.rmcc` timing 不一致，只提示，不自动修正。
