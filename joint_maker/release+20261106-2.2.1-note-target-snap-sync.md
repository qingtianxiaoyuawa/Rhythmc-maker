# RhythMC Maker 2.2.1：音符识别、吸附同步与撤销状态修复

- 日期：2026-11-06
- 模式：强劲 Bug 修复
- 版本：`2.2.0` → `2.2.1`

## Q1-Q4 完成确认

1. **统一识别链路**：新放置方块音符、展示实体音符、吸附后的音符都通过谱面 `id`、展示实体 `rhythmc_note:<chartId>:<noteId>` 标签和客户端 `NoteTargetResolver`/`NoteTarget` 解析；不再按来源分裂处理。
2. **吸附保持身份**：删除吸附流程中重新生成 UUID 的逻辑，吸附仅修改位置、Beat 和时间，原音符 `id` 保持不变。
3. **以谱面为准并即时同步**：右键修改和打开轨道吸附菜单前强制从当前 `.rmcc` 读取最新谱面；展示实体重建继续使用同一 `id` 标签，修复客户端旧索引导致的不同步。
4. **操作同步覆盖**：放置、破坏、WorldEdit 同步、修改位置/Beat、修改类型、Hold 粘合和解除粘合都会失效旧吸附撤销状态，并触发同一套谱面/展示实体更新链路。

## Q5 完成确认

- 打开轨道吸附菜单时使用最新 `.rmcc` 计算小数位置音符数量；无小数音符时“继续确认”立即灰化。
- 吸附后重新打开菜单时重新计算，按钮立即灰化。
- 任意玩家或命令音符修改会调用服务端撤销状态失效逻辑，客户端收到失效通知后立即灰化“撤销上次吸附”。
- 吸附后的音符保留原始 `id`，因此修改菜单、破坏保护和再次吸附可继续识别。
