## 根因与实现

### 模型与保存

- NoteEditingModel 统一坐标、时机、类型及变换校验。坐标菜单使用单轴命令，未修改的轴与 Beat 不再被小数格式化或旧客户端值覆盖。
- EditorBeat / NoteEditorDraft 保留用户未约分的 n+a/b 写法；分母 1–1000 仅用于此菜单及对应命令，其他地方的轨道分数 1–32 不变。
- 已复现并修复异步保存的 Gson 快照忽略 transient editorBeat，导致 editor.rmcd 无法保留原写法的问题；草稿随独立快照复制。
- 服务端图表快照与客户端分离，避免待确认客户端布局直接覆盖服务端图表。

### 几何与目标解析

- 展示方块从角原点转换为统一模型中心；按缩放与三轴旋转后的八个角计算轴对齐外接框，命中包含整个可见模型。
- 自动保存显式换算展示中心与存储原点，修复每次把中心当原点写回而增加 0.5 的漂移。
- 方块、变换展示实体和视觉补足使用不同的表示判定；更新时保留修改前完整表示，避免旧实体/方块残留及误删同位置的其他方块。

### HOLD 组与官方格式

- HEAD / TAIL / MEMBER 是编辑身份；只编辑真实头尾。有效组拒绝重合或倒置 Beat，异常组锁定数值，但允许整组删除；组类型禁止与普通音符互换。
- 普通 HOLD 与 HOLD组 区分。旧格式 length=1 不再错误分组。普通音符转换为 HOLD 时固定到 HOLD 层；导入的历史播放位置不因打开菜单而改写。
- 同组号在不同 trackId 下独立；吸附保持身份，避免短组落在同一 Beat 或形成倒置。
- 视觉补足不进入本地谱面真实音符、官方导出、正式判定列表或 Hold 判定成员；按真实成员重建稳定 ID，支持重新进入和轨道重建。
- 导入的真实中间成员保持其几何，端点时机修改不把原有路径压成直线。
- 提供的源码 ZIP 和 RhythMC-MOD-0.5.2-beta.1.jar 的 Note 签名均确认 holdGroup 是官方字段，必须保留；holdRole、visualOnly、editorBeat 和 Maker ID 不进入官方导出音符。
- 官方导出使用 noteType / beat / pos / scale / rotation / holdGroup。官方无须读取 editor.rmcd 或 Maker 布局文件即可播放本轮导出的音符。

### UI、轨道与 HUD

- X 范围由 (laneCount-1)/2 确定，中心为 0；普通音符相对 Y 为 0...trackHeight-1，HOLD/HOLD组 不开放 Y 修改。
- 坐标步进 0.05；缩放 1.0–3.0 / 0.1；旋转 -180–180 度 / 0.5；滑条保留未操作的历史值，支持 Ctrl+左键输入，输入及业务层分别校验。
- 越界 Beat 步进提前灰化，非法输入回到合法值；删除、关闭位于滚动内容之外的底部。
- 仅修改音符菜单的首次默认面积受显示面积 1/3 限制；使用 FirstUseEver，玩家放大后重开不强制缩回。
- 设置、谱面、吸附窗口允许调整并保存原生 ImGui 尺寸，关闭页面及退出时保存 ini。特效编辑器已有可保存面板保持不变。
- 修复设置页分支漏 endChild。并排区域共用实际高度和剩余宽度，窄窗口改用分类选择，避免侧栏遮挡和底部溢出。
- 轨道高度下拉框 3/4/5，顶部世界坐标 68/69/70；菜单预填、HUD、布局、缓存和结构重建同步，修改轨道分数不丢失高度。
- 降低高度遇超高音符时阻止修改并说明原因，不压缩、不删除音符，不改变既有播放位置、缩放或旋转。
- 吸附候选仅在打开菜单时检测，忽略视觉补足，不每帧扫描谱面。
