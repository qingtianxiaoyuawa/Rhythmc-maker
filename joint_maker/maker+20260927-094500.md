# RhythMC Maker UI 崩溃修复记录

- 时间：2026-09-27
- 任务：分析 `错误报告-2026-9-27_9.37.05.zip` 中使用新 UI 后的客户端崩溃并修复。

## 根因

- 崩溃报告明确为 `Description: Rendering screen`，首个异常是 `java.lang.IllegalStateException: Can only blur once per frame`。
- 受影响界面是 `cn.frkovo.rhythmcmaker.client.ChartListScreen`，调用链经过自带兼容层 `io.wispforest.owo.ui.base.BaseOwoScreen`。
- `BaseOwoScreen.render` 手动调用 `renderBackground`，在 Minecraft 1.21.11 的屏幕渲染流程中造成同一帧重复执行背景模糊；因此不是 ImGui native 加载失败，也不是 WorldEdit/其他模组的首要异常。

## 修复

- 删除 `BaseOwoScreen.render` 中的手动 `renderBackground` 调用，保留 ImGui 窗口渲染和输入处理。
- 版本从 `1.4.0` 提升为 `1.4.1`。
