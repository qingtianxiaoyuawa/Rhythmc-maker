# 1.13.7 时间轴选择输入边界修复

模式：微小 bug 修复。

## 要求与根因
- 普通左键/右键点击引起的选择、取消选择仅限时间轴区域；点击参数面板、特效库、游戏预览等非时间轴区域不得清空或替换现有选择。
- 时间轴发起的拖动允许鼠标离开时间轴，保持移动与释放处理。
- 根因：clearEffectSelection 的点击条件未检查时间轴 hovered，导致所有区域的鼠标点击都可能清空选择；此前已有的事件单选与右键命中分支有时间轴限制。

## 修改
- 给清空选择的左/右键点击条件增加时间轴 hovered 限制。
- 未达到拖动阈值的释放单选，仅在时间轴内释放时执行，避免边缘按下、区域外释放时误改单选。
- 不给整个输入处理加区域外早退；保留原有事件拖动、框选拖动、滚动条/播放头拖动以及区域外释放结算。
- 不修改右键菜单动作、复制删除语义、参数修改、Alt+滚轮、摄像头记忆及现有框选规则。

## 自检
- 对修复的实际源代码条件进行匹配检查，并检查 32 组布尔条件真值表；区域外左右键及无点击不触发清空，时间轴空白点击清空，命中事件交给原有选择规则处理。
- 静态核对未拖动释放的 hovered 限制，拖动更新与 finishTimelineDrag 仍不受时间轴 hovered 限制。
- git diff --check 通过；Gradle build --offline --no-daemon 成功，test NO-SOURCE。
