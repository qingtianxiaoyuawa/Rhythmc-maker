# RhythMC Maker UI 崩溃修复与风险加固记录 - 2026-09-27

## 核心结论
- 崩溃报告的首个致命异常为 `IllegalStateException: Can only blur once per frame`。
- 调用链明确指向 `BaseOwoScreen.render` 中的 `renderBackground`，当前 Minecraft 1.21.11 屏幕渲染流程已执行过一次 blur，Maker 再次请求 blur 导致 `ChartListScreen` 绘制阶段崩溃。
- 第二轮风险扫描未发现 ImGui begin/end 数量不平衡；同时加固了共享帧收尾和可选原生扩展降级路径。

## 修改文件
- `src/main/java/io/wispforest/owo/ui/base/BaseOwoScreen.java`
  - 移除会触发重复 blur 的 `renderBackground` 调用。
  - 使用纯色覆盖保留 UI 背景层，不改变页面布局和功能。
  - 用 `try/finally` 保证 ImGui 窗口与帧在组件异常时完成收尾。
  - 增加 adapter/root 空值保护。
- `src/main/java/cn/frkovo/rhythmcmaker/client/ImGuiExtensionRuntime.java`
  - ImPlot/ImNodes 原生扩展初始化同时捕获 `LinkageError`，扩展不可用时降级为普通 UI，不让客户端初始化直接崩溃。

## 保持不变
- 未改动谱面、场景、特效、音频、导入、导出、按钮回调或数据格式。
- 未改动 `MouseMixin` 输入逻辑。
