# 1.13.5 特效编辑器交互修改

模式：特定功能修改。以本轮最终确认及 Q1–Q63 为准，不改变现有框选逻辑，不增加其他多选方式。

## 实现
- 多选复制/删除从右侧参数面板移至事件右键菜单；保留原有单事件、轨道、空白区域菜单内容。
- 右键已选事件保留多选；右键未选事件改为单选。非事件区域点击清空选择，菜单内部操作不穿透时间轴。
- 左键按下已选事件保留选择，释放未超过 3 像素阈值才改单选；超过阈值开始拖动。
- 多选统一 beat 增量，保留相对时间与各自轨道。单选按每 chunk 分数网格移动；纵向达到一行 24 像素阈值后瞬间切换合法同类型轨道，不重置水平锚点。
- 不同类型轨道不接收事件圆点；鼠标可自由移动，水平拖动仍生效。
- 松开统一检查：同类型、同轨道、beat 精确相等即冲突；包括移动事件之间。越界或冲突整体回滚数据、轨道、分数、选择和修改标志，失败不产生撤销记录。
- 失败状态复用左侧状态显示：特效不能重叠 / 特效不能移出时间轴范围。
- 复制保留现有定位逻辑，新复制事件全部选中；删除清理已删除项，单项删除时重新映射仍存在的选中索引。
- 撤销快照保留完整多选；关键帧维持原有单点拖动逻辑，不参与事件重叠判断。
