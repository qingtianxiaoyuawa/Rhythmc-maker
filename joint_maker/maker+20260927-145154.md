# ImGui 界面不可见修复记录 - 2026-09-27

## 现象与根因
- 用户截图中 Minecraft 暗化背景正常，但 RhythMC Maker 的 ImGui UI 完全不可见。
- 对照 Axiom 5.4.2 的 GLFW/GL3 后端可见，ImGui 帧输入必须先由 GLFW 后端采集，再使用渲染目标一致的显示尺寸与 framebuffer scale 绘制。
- 本工程此前先设置 Minecraft GUI 尺寸，再调用 `ImGuiImplGlfw.newFrame()`；该调用会用原生窗口像素尺寸覆盖 ImGui 显示尺寸，随后实际 UI 坐标与 Minecraft GUI 坐标不一致。绘制时还手动强制切换 framebuffer 0，绕开 GL3 后端自己的状态备份/恢复。

## 修改文件
- `src/main/java/cn/frkovo/rhythmcmaker/client/ImGuiRuntime.java`
  - 将 `glfw.newFrame()` 移到每帧尺寸设置前；之后按 Minecraft GUI scaled width/height 设置 ImGui display size。
  - framebuffer scale 按 framebuffer 实际宽高除以 GUI scaled 宽高计算，避免 DPI/GUI scale 下坐标错位。
  - GL3 后端使用默认 GLSL 初始化，并删除外部强制绑定 FBO 0/手工还原 framebuffer 的代码，交由后端管理 GL 状态。
  - 首帧日志改为输出 draw-data framebuffer scale，便于诊断显示比例。
