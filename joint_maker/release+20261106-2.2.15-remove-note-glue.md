# RhythMC Maker 2.2.15 - 移除音符粘合功能

- 模式：功能移除 / Bug 修复维护。
- 移除制谱器修改音符界面的粘合与解除粘合入口及其临时状态。
- 移除 glue/unglue 命令注册和服务端实现、备份音符恢复、粘合专属破坏保护、状态解析及未使用的分组合并器。
- 从谱面模型移除 holdBackupId，并移除只验证编辑器粘合行为的测试。
- 保留正常 Hold 区间/分组播放表达及 Hold 时序字段，不移除长 Hold 播放逻辑。
- 随粘合功能整体移除 X 轴粘合；普通音符 X 坐标语义不变。
- 验证：Java 21 下 `gradlew check --offline --no-daemon` 与 `gradlew build --offline --no-daemon` 均成功；Hold playback regression 通过。
- 部署：`Rhythmc 3.0/mods/rhythmc-maker-2.2.15.jar`，SHA-256 `639F934A44F8B34FC314D40E6B1C8E48741DDA69EB7496074A028F8B4989F390`。
- 备份：目标 mods 中的 2.2.13 与 2.2.14 已备份至 `bak`。运行中进程锁定 `rhythmc-maker-2.2.13.jar`，未强制终止或删除；2.2.14 已移除。
- Git 提交与推送：随 2.2.15 版本变更提交至 origin/master。
