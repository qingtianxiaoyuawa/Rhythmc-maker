# Flashback 风格 UI 与 Owo-lib 渐进移除方案

- 日期：2026-10-01
- 目标一：借鉴 Flashback 编辑器 UI 的工作台布局、密度和交互层级，重做 RhythMC Maker 主界面。
- 目标二：逐步移除对当前工程内 Owo UI 实现的依赖，最终主界面与辅助界面统一由 Maker 自有 ImGui UI 实现。
- Planner 边界：本轮只做只读分析与规划；不修改源码、不编译、不测试、不部署。
- 参考 JAR：`F:\b晴天小雨awa\程序\我的世界PCL\.minecraft\versions\Rhythmc 3.0\mods\Flashback-0.39.10-for-MC1.21.11.jar`。

## 当前工程事实

- Minecraft 1.21.11，Fabric 客户端模组，当前 ImGui Java binding 已包含在工程依赖和构建产物中。
- 当前工作台/屏幕体系混合使用 ImGui runtime 与 Owo 风格 UI。
- `RhythmcScreen` 继承工程内的 `BaseOwoScreen`，页面大量使用 `FlowLayout`、`UIComponents`、固定宽度面板和垂直滚动容器。
- `KeyboardMixin` 通过 `BaseOwoScreen` 判断是否向当前屏幕转发字符输入；`MouseMixin` 也有 Owo 专属输入分支，需要迁移时一并检查。
- 当前并非 Gradle 直接声明外部 owo-lib：`build.gradle` 的 dependencies 中没有 owo 依赖坐标。工程在 `src/main/java/io/wispforest/owo/...` 内携带约 19 个 UI 源文件，约 38 个工程 Java 文件存在 Owo 类型或包名引用。
- 因此本计划所说“移除 owo-lib”具体指：移除工程内 Owo UI API/命名空间、继承体系和其仿制组件，不只是删一条 Gradle dependency。
- 用户提供的 Flashback 截图显示：顶部窄菜单栏、中央大面积世界预览、右侧窄检查器、底部常驻时间轴；暗灰色低对比面板、细分隔线、紧凑控件、蓝色仅作交互高亮。导出选项以居中小型模态窗口显示。
- Flashback JAR 元数据确认其为 Fabric 1.21.11 模组，包含自有编辑器 UI、时间轴、轨道/关键帧和导出 UI 类。只借鉴截图可见的设计与通用交互，不复制其源码、资源或专有实现。

## 方案原则

1. 新主 UI 采用 Minecraft Screen + 工程现有 ImGui runtime 绘制，不再基于 `BaseOwoScreen`/Owo adapter。
2. 最终主屏幕、模态窗口、辅助选择器、导入导出对话框均由 Maker 自有 UI 实现；迁移期允许新旧界面短暂并存，但最终验收必须没有 Owo 源码引用。
3. 将 UI 绘制与业务状态分层：屏幕负责布局和事件分发；可复用控件负责绘制/输入；业务服务继续承担谱面、场景、文件、播放和导入导出逻辑。
4. 先迁移入口与通用控件，再迁移低风险辅助页面，再搭建工作台，最后迁移时间轴和高交互编辑面板；每阶段保持可运行，不做一次性推倒重写。
5. 保持谱面模型和文件语义不变：`.rmcc`、`.rmcd`、`.schem` 的定义、Beat 时间域、BPM 分段、offset、播放与音频边界不因 UI 迁移而改变。
6. 保留当前 ImGui 生命周期、Minecraft framebuffer 合成顺序、字体字节加载、中文字符输入和剪贴板修复，不在 UI 改造时回退这些已修复能力。

## 目标工作台布局

```text
┌──────────────────────────────────────────────────────────────────┐
│ 文件  编辑  谱面  场景  播放  视图  帮助       保存状态 / 工具按钮 │
├──────────────────┬─────────────────────────────┬─────────────────┤
│ 可选资源/轨道树   │                             │ 右侧上下文检查器 │
│ 默认可收起        │       Minecraft 场景预览     │ 分组、折叠、滚动 │
│                  │                             │                 │
├──────────────────┴─────────────────────────────┴─────────────────┤
│ 播放控制 / Beat 与时间尺 / 播放头 / 音符、特效、相机、场景轨道     │
└──────────────────────────────────────────────────────────────────┘
```

- 中央场景预览是视觉焦点，默认占据最大空间。
- 右侧检查器固定在屏幕右侧，随选中对象切换内容；无选择时展示谱面/场景属性。
- 底部时间轴常驻，可折叠和拖动高度；支持独立缩放、水平滚动和播放头定位。
- 左侧轨道/资源栏默认收起，避免压缩预览区；需要管理对象时再展开。
- 文件、导入、导出、设置和确认类 UI 使用 Maker 自有紧凑模态框，而不是继续留用 Owo 页面。

## 分阶段迁移路线

### 阶段 0：建立 Owo 依赖清单与迁移护栏

- 编制 Owo 类型、文件、屏幕入口、输入分支、表单业务动作和文件操作的映射表。
- 将 UI 调用的业务动作与绘制代码区分开，确认保存、创建、导入、导出、场景编辑、物品选择、谱面列表等现有能力的真实调用入口。
- 盘点 `src/main/java/io/wispforest/owo/...` 下工程内携带的源文件及其相互依赖；标记可删文件与迁移后再删文件。
- 暂不删除任何 Owo 源文件，先确保每项现有功能都有新 UI 的迁移目标和验收点。

交付：Owo 引用清单、页面迁移矩阵、业务动作复用清单。

### 阶段 1：自有 ImGui 屏幕与控件基础层

- 新建 Maker 自有的基础 Screen/Workspace Screen 生命周期，不继承 `BaseOwoScreen`。
- 建立统一主题：背景色、面板色、边线、文本层级、控件高度、间距、焦点、悬停、禁用和错误状态。
- 建立控件基础：标签、按钮、图标按钮、文本框、数值框、复选框、下拉菜单、折叠分组、滚动区、弹出层、模态窗口、提示条。
- 建立布局辅助：菜单栏、水平/垂直布局、分栏、可拖动分割线、视口裁剪和最小尺寸规则。
- 统一输入路由，提供屏幕级 keyboard/text/mouse/scroll/focus API；组件可声明键盘焦点和滚轮消费权。
- 保留现有 Owo 页面继续运行，让新旧界面逐页并存。

验收：新基础 Screen 能处理 Esc、字符输入、剪贴板、键盘重复、鼠标按钮、滚轮、焦点切换和窗口缩放；ImGui 输入不会误传给游戏控制。

### 阶段 2：迁移低风险辅助页面并替换 Owo 输入耦合

按复用基础组件的难度分组迁移：

1. 确认/最终确认窗口、占位设置页、简单播放设置。
2. 创建谱面、谱面信息、谱面详情和列表页。
3. 导入谱面、导入场景、导出谱面、文件选择器。
4. 物品选择器、场景编辑/删除/重置流程。
5. 特效轨道编辑及包含图表/绘图控件的页面。

要求：
- 把 Owo 页面中的点击回调连接到原有服务/方法，不在 UI 中重新实现数据规则。
- 原有每一个按钮、键盘快捷键、确认步骤、取消返回路径和错误提示都要有迁移映射。
- `KeyboardMixin`/`MouseMixin` 不再根据 `BaseOwoScreen` 判定输入；改由 Maker Screen 标记接口或统一的 UI 输入路由判断。
- 对文件选择器、文本框和滚动区域重点验证中文输入、剪贴板、删除、键重复、鼠标焦点和滚轮分发。

阶段门：迁移的屏幕不再 import Owo 类型，但尚未迁移的屏幕允许继续使用 Owo。

### 阶段 3：建立 Flashback 风格主工作台空壳

- 新工作台成为 Maker 的主编辑入口；顶栏、左侧栏、中央预览、右侧检查器、底部时间轴先只显示布局与空状态。
- 支持右侧栏、左侧栏、底部时间轴折叠；拖动分割线改变宽度/高度；保存合理的布局状态。
- 最小窗口尺寸和窄屏布局必须有明确降级：优先保留预览和时间轴控制，侧栏自动折叠而非互相覆盖。
- 设置所有主面板为统一低对比暗色、细分隔线、紧凑控件；避免堆叠卡片与大块渐变/描边。
- 保留 Minecraft 鼠标视角与 ImGui 控件操作之间的正确焦点切换。

验收：新主工作台空间关系接近参考图，即使数据仍为空，也不再表现为居中表单页面。

### 阶段 4：迁移主编辑功能与时间轴

- 先接入谱面标题、播放/暂停/停止、当前位置和已有播放业务入口。
- 接入当前谱面数据的只读显示：音符、特效、相机/场景事件和轨道列表。
- 时间轴以 Beat 为主要编辑坐标，秒数仅用于辅助标签；遵循已有 BPM 分段、offset 和速度映射规则。
- 实现播放头、网格刻度、缩放、水平滚动、选区与可视区裁剪；大谱面不得每帧全量重建控件或执行磁盘保存。
- 先只读呈现，再增加选择/属性编辑，再增加拖动、复制和删除，避免一次性引入大量交互风险。
- 右侧检查器按当前选择显示谱面级、轨道级或对象级属性。

验收：原有播放时间语义不变；时间轴滚动/缩放不干扰预览相机或检查器滚动；长谱面视口外事件不会全部实例化成 UI 控件。

### 阶段 5：删除 Owo 源码和残余声明

只在下列条件全部满足后执行：

- 全部运行入口、页面、弹窗、文件选择和组件都已替换。
- 生产源码不再有 `io.wispforest.owo`、`BaseOwoScreen`、`OwoUIAdapter`、`FlowLayout`、`UIComponents` 等引用。
- `KeyboardMixin`、`MouseMixin`、screen 导航、返回栈和模态关闭逻辑均不再依赖 Owo 类型。
- `src/main/java/io/wispforest/owo/...` 内携带的 UI 源文件不再被业务层依赖，可以整体删除。
- `build.gradle`、资源、Mixin 配置、文档和打包脚本中不存在 Owo 运行时/反射/资源入口残留。

删除后由实现/编译合作方执行全工程引用搜索、编译、构建与运行时冒烟检查。Planner 不代执行验证。

## 设计基准

- 顶栏约 22–26 px；主工具控件约 20–24 px；紧凑控件约 18–22 px。
- 右侧检查器约 260–310 px；可折叠；窄屏时收缩或隐藏。
- 时间轴初始高度约 180–230 px，允许拖动调整。
- 左侧栏默认关闭，展开宽度约 190–240 px。
- 面板采用近黑/深灰蓝；分隔线低对比；蓝色只强调选中、播放、拖动、确认等动作。
- 中文字体沿用工程现有 Misans 字体资源；主界面最多使用三档字号，避免标签与输入值层级混乱。
- 避免所有内容都包在大卡片内；更多使用单色面板、分组标题、细线分隔和适度留白。

以上尺寸是初始设计基准，必须在实际 Minecraft GUI 缩放和窗口尺寸下调整，不能硬编码成唯一布局。

## 关键风险及控制

- **迁移跨度大**：Owo 风格引用覆盖约 38 个工程 Java 文件。以功能分组迁移，每组完成后再清理引用，避免一次性全改造成难以定位的输入/布局回归。
- **自建控件功能不完整**：优先建立焦点、文本输入、组合框弹层、滚动裁剪、键盘导航和无障碍标签等基础行为，再迁移复杂表单。
- **Minecraft 鼠标捕获冲突**：明确区分预览区与 UI 控件区；点击 UI 时释放相机控制，离开 UI 或按快捷键后按既有语义恢复。
- **模态窗口生命周期**：新模态系统需支持 Esc 取消、父子弹窗、文件选择返回、错误状态和关闭后恢复焦点。
- **误改业务规则**：UI 只调用现有业务服务/命令，不重写序列化、Beat 映射、播放会话和场景持久化。
- **ImGui 帧/Framebuffer 回归**：保持当前每帧上下文、渲染注入时序和 GL 状态保护；任何主 UI 改造都不得把绘制移回 Minecraft 最终画面合成之前。
- **进度状态误判**：最近 maker 记录截至 2026-09-30 23:59:59，最新两项分别为 UI 字体崩溃修复和播放链路修复；均记录有待完全重启游戏后的运行时确认。新 UI 实现前应以最新实际工程和运行状态为准，不假定这些验收已经完成。

## 给实现方的总任务清单

1. 先输出 Owo 引用/页面/业务入口迁移矩阵，不先删文件。
2. 新增 Maker 自有 Screen、主题、控件、焦点/输入路由和模态窗口基础层。
3. 按辅助页面、导入导出、列表选择器、场景编辑、特效编辑的顺序逐组替换 Owo 页面。
4. 新建 Flashback 风格工作台并设置默认主入口。
5. 将谱面、播放、对象选择、右侧检查器和 Beat 时间轴逐项接入新工作台。
6. 对照用户截图逐轮调整空间比例、紧凑度、颜色和控件对齐。
7. 全量确认功能入口与输入链路后，删除工程内 Owo UI 源文件及剩余类型耦合。
8. 最后由编译合作方运行静态引用扫描、Gradle 编译/构建、Minecraft 启动和功能/截图验收；有失败先按模块定位，不恢复旧架构作为长期方案。

## 最终验收标准

- 主 UI 的布局明显借鉴 Flashback：顶部菜单、中央世界预览、右侧检查器、底部常驻时间轴，左侧资源栏可选。
- 导入、导出、创建、文件选择、设置、确认、场景编辑、物品选择等辅助操作均使用 Maker 自有 UI，视觉和输入统一。
- 工程源码、构建声明、Mixin 与资源中不再存在 Owo UI 类型/命名空间依赖。
- 搜索 `io.wispforest.owo`、`BaseOwoScreen`、`OwoUIAdapter` 等标识无生产代码命中；工程内 Owo UI 源文件已移除。
- 中文字符、IME/字符事件、Ctrl+A/C/V/X、Backspace/Delete、按键重复、Esc、鼠标焦点和各面板滚轮行为正常。
- 旧有谱面、播放、场景、导入导出功能的语义和文件格式保持兼容。
- 屏幕尺寸改变、不同 GUI 缩放、长谱面和长表单下无裁切、重叠、双滚动条或明显卡顿。
- 运行时截图与交互实测由实现/编译合作方完成并留记录。

## 本轮结论

最终目标明确为“Flashback 风格工作台 + 全面移除工程内 Owo UI 依赖”。允许迁移阶段暂时保留 Owo 页面以保证增量可用，但 Owo 不作为最终架构的一部分；不建议将其继续保留为永久兜底或模态窗口方案。
