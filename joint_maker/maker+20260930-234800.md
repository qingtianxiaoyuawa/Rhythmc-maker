## 本轮修复

1. 字体：从用户提供的资源包提取 `assets/minecraft/font/misans-bold.ttf`，复制到模组资源 `assets/rhythmc_maker/fonts/misans-bold.ttf`，运行时解包到实例目录后加载，不再依赖 Windows SimHei。

3. 字体输入范围：保留简体中文 glyph ranges，并使用默认字体作为拉丁字符回退。
4. 输入框：补充 GLFW 系统剪贴板读写回调、按键重复速率、光标闪烁和拖拽选中文本支持；字符事件改为传递完整 codepoint，不再先截断成 Java `char`。
