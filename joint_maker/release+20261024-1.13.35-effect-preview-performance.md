# 1.13.35 Maker 特效预览性能优化

日期：2026-10-24
模式：特定性能优化（P0 + P1）

## 实现

- 时间轴 seek 改为单槽最新 Beat，由客户端 END_CLIENT_TICK 处理；最大发送频率受客户端 tick 限制（通常约 20 次/秒），释放鼠标时立即 flush 最终目标。
- seek 仅在实际提交时同步服务端；播放中仅在提交事务重启本地音频，拖动采样不再直接发送命令或重启音频。
- TextDisplay 轨道姿态计算改为每会话、每轨道复用 PoseBuffer，并在每次更新周期最多求值一次。
- 姿态差分缓存原位更新，避免每 tick 创建 Pose record、HashMap、临时姿态数组及位置/旋转/缩放数组。
