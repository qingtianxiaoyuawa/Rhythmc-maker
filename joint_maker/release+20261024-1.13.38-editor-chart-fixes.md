# Release 1.13.38 - Large Chart Import and Editor Fixes

Date: 2026-10-24

## Changes

- Prevent deleting scenes referenced by the initial-scene binding or ARENA effects; maintain scene bindings when scenes are reordered.
- Correct imported initial-scene name precedence: explicit imported values replace existing values, while absent fields preserve existing names; accept the 3.0 `initial-arena` metadata key.
- Rebuild editor tracks incrementally per server tick and prevent overlapping entry/adjustment tasks.
- Preserve in-progress track generation when entering a chart and detect incomplete tracks using built length, lane width, and divisions per beat; report progress.
- On disconnect from a chart dimension, clean up playback, queue scene capture, return the player to the hub, and update the hub respawn point. Preserve the existing login-time return flow.
- Move 3.0 chart file reads, JSON/YAML parsing, audio staging, and conversion to a background worker; keep world and scene mutations on the server thread.
