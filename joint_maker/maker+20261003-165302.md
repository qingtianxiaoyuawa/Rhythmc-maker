# Rhythmc Maker 1.5.31 修改记录

## 药水效果接入

- 补全 2.0 `EFFECT` 药水 ID 到 Minecraft 标准 ID 的转换。
- 支持 `JUMP`/跳跃提升、`SLOW`/缓慢、`NIGHT_VISION`/夜视、`INVISIBILITY`/隐身，以及速度、力量、抗性、失明、黑暗、漂浮、再生、抗火、水下呼吸、发光、中毒、凋零等标准效果。
- 兼容 2.0 的 `effect-id`、`effect`、`potion`、`potion-effect` 字段，包含嵌套 `properties` 字段。
- `CLREFFECT` 转换为 3.0 `CLEAR_EFFECT` 时支持按指定效果清除；无指定效果时清除全部效果。
- 正式播放仍使用效果等级、持续时间、环境标记和粒子标记，并在播放结束/停止时清理玩家药水效果。
- 3.0 已保存的旧别名（如 `JUMP`、`SLOW`）播放时也会运行时标准化。
