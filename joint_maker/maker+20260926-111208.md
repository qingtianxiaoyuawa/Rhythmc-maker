# RhythMC Maker 工作记录

## 本轮需求
- 优化滚动播放卡顿。
- 优化大量区块/轨道生成时的渲染卡顿。
- 参考 F3+1 右侧性能饼图检查其他掉帧来源。

## 工作流程
1. 阅读项目 `AGENTS.md` 与最近工作记录；本轮未要求应用 planner，因此未读取 planner 文件。
2. 根据截图确认主要占比为 `guiExtraction 76.39%`、`guiRendering 12.49%`，`world 10.57%`；同时确认 Integrated Server 约 `4.3/50.0 ms`，服务器 tick 不是首要瓶颈。
3. 检查滚动播放服务端 tick、音符时间线、场景/轨道批量方块写入路径。
4. 对播放会话缓存音符有效时间和结束时间，避免滚动播放每 tick 重复计算音符时间并扫描整张谱面。
5. 将场景编辑区、轨道基础结构、轨道列复制/清理/末端屏障的批量方块更新从带邻居更新的标志 `3` 改为仅通知监听器的标志 `2`，减少邻居更新和区块重建压力。
6. 使用本地 Java 21 与 Gradle 9.2.1 完成定向编译和完整构建。
