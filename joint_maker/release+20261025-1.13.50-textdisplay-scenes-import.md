# RhythMC Maker 1.13.50

## 修复内容

- 中途起播时按已播放歌曲时间扣减全息文字/文本展示持续时间；已到期事件不创建显示实体，未到期事件以剩余持续时间继续播放。
- 特效编辑器顶栏将曲名、BPM 与保存状态限制在按钮左侧的单行区域，长文本裁剪，不挤压右侧操作按钮。
- 隐藏音符轨道 ID 恢复为必需参数；空 `tracks` 表示未指定轨道。2.0 `VISIBLE` 迁移时丢弃旧轨道字段并输出空轨道列表，因为 2.0 不定义轨道。
- 3.0 场景绑定基于编辑器实际场景索引；初始场景和普通场景按输入顺序映射，重复名称遵循后导入绑定覆盖前绑定。
