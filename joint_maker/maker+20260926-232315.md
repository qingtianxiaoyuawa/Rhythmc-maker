## 根因与修改

1. 旧展示实体只按谱面 ID 和 note ID 判断有效；音符位置改变后，旧实体仍带有相同 note ID，因此视距外或后续重新加载时不会被识别为过期。
2. 为编辑器音符展示加入显示代次标签。布局切换会使代次失效；当前已加载实体在刷新任务完成后清理，未加载实体在区块加载时按代次清理。
3. 展示刷新改为分批生成，并避免切换布局时同步扫描并清空整张谱面的展示实体。
4. 删除 estoreEditorTrackFoundation 中按整条轨道同步写入装饰方块的循环，长轨道统一交给已有的分 tick 装饰任务处理。
5. 将轨道装饰重建和旧轨道清理的单 tick 列预算从 256/96 降为 8，限制单 tick 方块更新量，避免调整参数时主线程长时间阻塞。
6. 版本按规则由 1.2.4 更新为 1.2.5。
