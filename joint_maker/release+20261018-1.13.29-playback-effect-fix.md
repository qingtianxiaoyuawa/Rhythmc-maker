# Rhythmc Maker 1.13.29 — playback effect fixes

## Changes

- Dispatch `TIME` and `WEATHER` effects from the formal playback effect runner; the existing world-time packet and weather application logic is now reachable.
- Keep the existing end-of-playback weather reset and do not reset world time at playback end.
- Process judgement sounds for hidden notes independently of display entities, so hiding only removes visuals and does not suppress note sounds.
- Skip hidden notes before block-display acquisition, preventing a one-tick visual flash when a note is reused or preloaded.
- Change new `TEXT_DISPLAY` and `TEXT_DISPLAY_EFFECT` position defaults to `[0,1.5,0]`; runtime fallbacks use the same offset.
