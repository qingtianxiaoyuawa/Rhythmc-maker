## 本轮需求
- 移除离开播放区域场景编辑区域时保存播放场景结构。
- 移除快捷功能中的“传送到播放场景”。
- 将场景边缘粒子改为整面显示，并蓝白交替。

- `src/main/java/cn/frkovo/rhythmcmaker/RhythmcMaker.java`
  - 场景编号 1（播放区域初始场景）离开编辑区时不再触发自动保存。
  - 玩家断开连接时也不再保存场景编号 1，避免绕过离区规则。
  - 场景边缘粒子由立方体棱线改为六个边界面，使用蓝色与白色粒子按步进交替显示。
  - 面粒子仍按 `SCENE_BORDER_STEP` 采样，避免每 tick 发送过量粒子数据。
- `src/main/java/cn/frkovo/rhythmcmaker/client/PlaceholderScreen.java`
  - 删除快捷传送菜单中的“传送到播放场景”按钮；保留 Chunk、歌曲时间和制谱器平台传送。
- `build.gradle`
  - Java 编译启用增量编译和 fork 编译进程。
- `gradle.properties`
  - 保留并行、最大 worker、构建缓存和按需配置；未启用与现有 `jar` 闭包不兼容的 configuration cache。
