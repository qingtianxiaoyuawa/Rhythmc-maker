# Rhythmc Maker 1.13.27 — local scene storage fixes

## Changes

- Restrict chart discovery to UUID chart directories containing the local `chart.rmcc` or `manifests.json`; exclude settings and legacy storage roots so startup no longer interprets them as charts or recreates legacy `charts` directories.
- Do not create an initial arena directory until it has a saved schematic. Persist effect scene metadata only in the UUID-based local scene folders.
- Generate the lowest available `effect_arena_N` name for new editor scenes.
- Reuse the chart cover inventory item picker for scene icons.
- Resolve arena effects by their scene name to the local `scene/scene-<UUID>/arena.schem` before consulting older saved bindings. Keep the index binding path for legacy chart data.
- Parse `display-name` from scene metadata so user-facing names survive reloads.

## Root-cause notes

- Chart listing previously treated every child directory of the Rhythmc root except `imports` and `exports` as a chart, invoking migration logic on unrelated folders.
- Scene metadata persistence previously materialized the synthesized initial scene even when it had no arena schematic.
- Playback depended on a saved name-to-index binding, while newly created scene-editor scenes were not guaranteed to have that binding; playback now resolves the exact local scene by its name first.
