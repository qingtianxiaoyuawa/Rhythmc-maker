# RhythMC Maker 2.2.7 发布记录

- 模式：bug 修复 / UI 调整
- 日期：2026-11-06
- 版本：2.2.7

## 修复内容

1. 时间轴事件横坐标改用 EffectTrackLayoutModel 的规范轨道位置 beat，保证同一时间不同轨道共用同一时间映射。
2. 特效事件标记由双三角形改为蓝色圆形。
3. 选中特效改为绘制白色外圈，不再使用底层白色填充，避免出现穿模/白色内嵌。
4. 移除特效参数面板的“新增关键帧”入口及当前新增关键帧方法。已有关键帧数据保留，正式播放逻辑未修改。
