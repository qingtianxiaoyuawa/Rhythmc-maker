# RhythMC Maker 工作记录

## 本轮需求
- 修复新建场景第一次点击“开始搭建”不生成平台和判定框。
- 重置场景必须恢复制谱器平台和判定框，并在完成前锁定其它场景编辑。
- 修复场景编辑菜单 UI 溢出。

## 修改内容
- `src/main/java/cn/frkovo/rhythmcmaker/RhythmcMaker.java`
  - 新建场景的异步生成任务现在携带谱面 ID 和场景编号，与重置任务使用同一任务状态。
  - 若首次进入时平台仍在生成，玩家不会被传送到空区域，而是进入等待队列；场地清理和默认平台/判定框生成完成后自动传送，并给予保存场景物品。
  - `sceneEditors` 在场景生成或重置任务存在时拒绝打开场景编辑菜单，返回明确提示，防止任务期间修改其它场景。
  - 重置命令反馈改为“重置任务已开始”，只有异步结构任务完成后才允许继续编辑。
- `src/main/java/cn/frkovo/rhythmcmaker/client/SceneEditScreen.java`
  - 场景编辑菜单改为固定高度页面和垂直滚动内容容器。
  - 修正空场景提示、删除按钮等控件加入滚动内容，避免小分辨率下溢出屏幕。

## 核心不变量
- 场景中心坐标和 128³ 编辑范围仍由服务端 `SceneEditorAreaTask` 统一管理。
- 新建和重置都先清理范围，再生成默认结构，不会把重置误当成清空。
- 重置/生成任务存在期间，场景编辑菜单不可正常打开；任务完成后恢复访问。
- 首次进入场景只能在默认结构生成完成后传送，避免空场地和错误编辑位置。
