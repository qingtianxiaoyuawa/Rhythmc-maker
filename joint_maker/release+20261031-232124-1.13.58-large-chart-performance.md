# RhythMC Maker 1.13.58 性能优化

- 模式：性能优化。
- 针对 22 MB、155145 个特效的样例谱面，减少导入、谱面列表和保存时的重复大对象序列化。
- 本地谱面列表优先读取 `manifests.json` 元数据，不再为列表展示解析完整 `chart.rmcc`。
- 启动阶段不再预先创建所有谱面维度，改为进入对应谱面时按需创建。
- 2.0 导入的文件解析与转换移出服务器 tick 主线程；场景维度写入留在服务器线程完成。
- 播放隐藏音符判断使用按时间推进的游标，恢复可见音符仅扫描有限窗口，避免每 tick 全谱扫描。
- 保持旧 `.rmcc` 读取结构与场景/音符/特效兼容；`compileJava` 与完整 `build` 已通过。
- 当前工作区已有历史改动未归属本次任务，发布时只提交本次源码、版本与本记录。
