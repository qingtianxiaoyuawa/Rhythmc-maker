# 1.13.44 世界进入与区块负载优化

日期：2026-10-25

## 根因与修复

- 每个服务端 tick 都遍历全部已加载谱面维度，并探测播放区 9×9 共 81 个区块；发现未加载区块时同步加载并强制保留。谱面维度累积后，这项工作跨世界重复执行，造成持续主线程负载、低 1% low 与频繁卡顿。现改为仅在播放初始化时按需加载，不再每 tick 重复探测，也不再新增永久强制区块票据。
- 清理旧维度配置时释放先前版本遗留的播放区 81 个强制区块票据，避免旧票据导致后续世界/维度重载额外恢复大量区块。
- 区块加载清理首次解析世界关联谱面时，旧实现通过 `ChartStorage.list()` 扫描谱面并逐一读取完整谱面数据，再查找维度 ID。现先按稳定维度 ID 匹配谱面目录/清单文件，仅解析匹配项，避免一次维度反查对所有谱面做完整反序列化。
- 未修改谱面格式、保存内容及播放时序。
