# Rhythmc Maker 1.5.28 修改记录

## 修改依据

- `joint_maker/planner+20261003-151916.md`

## 性能修复

- 为服务端活动谱面增加按谱面 ID 的运行时缓存；进入谱面后，放置、挖掘、轨道调整、场景编辑和播放相关查询优先读取内存对象，不再每次从磁盘解析完整 JSON。
- 谱面变更改为内存修改并递增修订号、标记 dirty；自动保存只提交有修改的谱面，无修改时不再重复序列化和写盘。
- 增加单线程谱面持久化队列，保存请求按顺序执行，避免多个保存任务并发覆盖同一谱面。
- 客户端设置和谱面信息更新统一进入缓存保存队列，避免 UI 操作同步写入大谱面文件。
- 保留此前的临时文件、原子替换和 `.bak` 恢复机制。
- 未改变播放、判定音、时间轴、音符坐标和轨道坐标计算逻辑。
