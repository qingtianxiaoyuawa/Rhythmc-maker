# Planner 设计记录：RhythMC 特效与轨道编辑 UI 设想

- 日期：2026-09-26
- 需求：参考本地 Axiom 6.0.5 与 Flashback 0.39.8 的 UI 工作流，结合 RhythMC 实际特效/轨道能力生成概念界面。

## RhythMC 已确认功能范围

- 特效类型包括：标题、消息、药水效果、天气、时间、烟花、全息图、文本显示、文本显示变换、文本显示同步/取消同步轨道、文本显示移除、隐藏音符、发光颜色、切换场景等。
- 轨道事件包含：速度、X/Y/Z 位移、X/Y/Z 旋转、X/Y/Z 缩放；另有音符轨道。
- 当前 Maker 已有 `EffectTrackScreen` 原型，支持按 Beat 添加/删除标题和闪光事件，但还不是专业时间轴编辑器。

## UI 借鉴方向

- Axiom：可停靠工具窗口、左侧工具/资源选择、搜索与预设、右侧属性检查器、世界内选中高亮和 Gizmo。
- Flashback：底部时间轴、关键帧/片段、播放头、相机/移动参数、预览窗口、导出控制。
- 生成图只借鉴交互组织和信息层级，不复制其代码、纹理或品牌视觉。

## 概念布局

- 左栏：特效/轨道 Tab、搜索、分类列表、预设。
- 中上：轨道俯瞰图/世界预览，显示实际 Minecraft 方块轨道、音符和选中对象。
- 中下：多轨时间轴，分组显示音符、速度、位移、旋转、缩放和效果事件；支持 Beat/秒双标尺。
- 右栏：选中事件属性、关键帧数值、缓动、颜色/文本/位置/旋转/缩放等参数。
- 底部：播放、循环、吸附、Beat 网格、撤销/重做、导入导出。
