# 2026-10-04 12:45 - 2.0 特效转谱与 TEXT_DISPLAY/HOLOGRAM 播放适配

## 检查结论
- 2.0 的 HOLOGRAM 旧字段为 `hologram-loc`、`hologram-contents`，旧转换仅改事件类型，未输出 3.0 所需的 `location`、`contents` 和毫秒 `duration`。
- 2.0 的 TEXT 旧字段为 `loc`、`content`，旧转换未输出 3.0 所需的 `position`、`text`、`rotation`、`scale`。
- 2.0 的 TRANSFORMATIONS 旧字段未完整转换为 `TEXT_DISPLAY_EFFECT` 的 `type`、`position`、`rotation`、`scale`、`targetOpacity`、`shadowed`、`color` 等字段。
- 播放端原先没有读取嵌套 `properties.contents`，且把 3.0 相对坐标当成世界绝对坐标，导致文本显示/全息可能出现在错误位置或没有内容。

## 修改内容
- 补齐 2.0 HOLOGRAM -> 3.0 HOLOGRAM 的位置、内容、ID、持续时间转换。
- 补齐 2.0 TEXT -> 3.0 TEXT_DISPLAY 的文本、位置、旋转、缩放、ID转换。
- 补齐 2.0 TRANSFORMATIONS -> 3.0 TEXT_DISPLAY_EFFECT 的背景色、阴影、发光、文本、透明度、线性变换和移除转换。
- 播放端支持多行 `contents`、相对播放场景坐标、旋转/缩放、透明度、背景色、阴影、发光和轨道同步变换。
- 保留 `TEXT_DISPLAY_REMOVE`、`REMOVE_HOLOGRAM` 的清理逻辑，并在显示到期时移除缓存状态。
