# Rhythmc Maker 1.13.28 — text preview fixes

## Changes

- Correct the Minecraft RGB to ImGui packed-color conversion so `&0` through `&f` and `§0` through `§f` display the expected colors; `&c` now renders red instead of blue.
- Keep parsing both `&` and `§` formatting codes, including bold, italic, obfuscated, strikethrough, underlined, and reset.
- Stop inserting visible marker glyphs such as `▌`, `╱`, and combining underline/strike characters into preview text.
- Render bold, strikethrough, and underline without changing the original preview content; obfuscated text remains obfuscated.
- Leave the editor font used by the rest of the UI unchanged.
