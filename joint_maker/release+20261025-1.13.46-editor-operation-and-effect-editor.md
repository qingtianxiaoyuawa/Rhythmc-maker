# 1.13.46 编辑器任务反馈与特效编辑器修复

## 修改内容

- 轨道调整、场景生成/保存、音符吸附及撤销期间锁定模组菜单，但保留 Minecraft 原生界面与输入；Esc 只退出当前模组界面，不取消后台任务。
- 新增 HUD 底部中央确定性百分比进度条，并以 action bar 每秒同步任务进度；未完成任务不提前显示 100%。
- 任务结束后通过统一 action bar 给出成功或失败结果；谱面进入和导出提示显示歌曲名，不暴露本地路径。
- 轨道调整完成时明确发送“制谱器轨道生成完成”。
- 从中途恢复播放时保留仍有效的 TextDisplay，并累计应用其变换；不因显示事件的短 duration 丢弃持久显示。
- 选择特效事件不再隐式触发全谱 seek/预览重建，避免大事件谱面选中时卡顿。
- 特效参数编辑减少事件表单扫描与渲染期重复列表构造。
- 进度查询移除迭代流临时分配，并将整数百分比计算改为长整型避免溢出。
