# Planner 记录：隐藏播放器与特效预览播放方案

- 日期：2026-09-26
- 用户需求：在不可见位置以 `(-400,65,0)` 为播放器中心完整播放谱面；右下角预览固定在 `(-399.5,66,-1)`，朝向 `-Z`；轨道过宽时允许左右移动；支持音符框选、按节拍进入纵剖面细分选择；播放起点前的场景/时间/发光等持久特效必须预加载。
- 本轮仅整理实现提示词，不修改源码、不编译、不部署。

## 关键约束

- 普通音符在该 UI 中只读，不提供音符编辑；框选和纵剖面选择用于查看、定位或绑定特效目标。
- 隐藏播放器必须使用与 RhythMC 正式播放同一套 BPM、offset、speedEvents、effects、Track 和音频时钟。
- 右下角预览不能依赖玩家当前视角；应使用独立预览相机/渲染目标或专用预览实体。
- 播放起点前的持久状态需要通过预加载恢复，不能只触发起点之后的事件。
