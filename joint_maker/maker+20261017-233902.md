# 2026-10-17 beat 术语统一与兼容

## 模式
特定功能修复：将节拍语义中的 chunk 统一更名为 beat，保留旧数据键和命令兼容。

## 本次修改
- 将领域属性、布局 API、配置项、编辑器显示文案与命令的新入口统一为 beat；旧 `rhythmc_*_chunk` 命令仍指向同一 beat 操作。
- 旧 `divisionsPerChunk`、`beatsPerChunk`、`chunkCount`、`selectedStartChunk` 与 `defaultDivisionsPerChunk` 作为读取迁移来源，保存写入新的 beat 字段。
- 3.0 谱面已有的音符 `beat` 及其值不变；`divisionsPerBeat` 仅表示每个节拍的编辑分数。迁移不改变分数、beat 数或播放起始位置的数值语义。
- 保留真实 Minecraft 区块 API、`ChunkPos`、区块清理任务及已有物品注册 ID；纠正批量改名造成的区块清理方法误命名。
- 将 beat 分数菜单项的 Java 符号改为 `BEAT_SCORE_ITEM`；保留既有 `chunk_score` 注册 ID，避免破坏存档物品识别。
- 修复编译发现的起播索引/小数 beat 状态变量冲突，并保证播放提示显示一基 beat 序号。
