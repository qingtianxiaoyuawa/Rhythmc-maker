## 两个 Mod 的结构结论

### Flashback

- abric.mod.json 的来源指向公开 GitHub，主许可证为 MIT；但当前安装的 JAR 中这些 UI 类仍是内部实现，没有面向 Maker 的稳定 UI API。

### Axiom

JAR：F:\b晴天小雨awa\程序\我的世界PCL\\.minecraft\\versions\\Rhythmc 3.0\\mods\\Axiom-6.0.5-for-MC1.21.11.jar

- UI/编辑器类主要在 com.moulberry.axiom.screen、ditor.widgets、ditor.windows、gizmo、ender 等包。
- 包含 META-INF/jars/axiomclientapi.jar，其公开 API 主要是 CustomTool、Effects、ToolRegistryService、ToolService、区域和路径服务，不是通用 UI 组件 API。

## 集成边界

### 不建议的方案

1. 直接 import com.moulberry.axiom.screen.* 或 com.moulberry.flashback.editor.ui.*。
2. 把两个 Mod 的 JAR 加进 Maker 的 Gradle include 或强制依赖。
3. 通过 Mixin 修改两个 Mod 的内部窗口来承载 RhythMC 特效。
4. 直接复制 Axiom 内部 UI 代码或类文件。

原因：版本耦合、用户未安装时崩溃、ImGui/OpenGL 上下文冲突、内部类无兼容承诺，以及 Axiom 的授权限制。

### 推荐方案

参考二者交互设计，但用 Maker 自己的 UI 和数据模型重写：

- 基础容器继续使用当前工程已有的 owo-ui/RhythmcScreen；
- 只在需要时间线、关键帧拖拽和高频属性编辑时，引入独立的 ImGui 层；
- 不依赖 Flashback/Axiom 是否安装；
- 若未来确认要用 Dear ImGui，直接选择有明确许可证的官方/独立 Java binding，并单独处理原生库，而不是从 Flashback JAR 借类。

## 借鉴的交互模式

### Flashback 风格

可借鉴：

- 顶部菜单/工具栏；
- 可折叠、可停靠的窗口；
- 底部时间轴；
- 关键帧/事件轨道；
- 时间指针拖动、区间选择；
- 左侧对象/轨道列表，右侧属性检查器；
- 预览区和编辑区分离。

### Axiom 风格

可借鉴：

- 工具栏和工具状态切换；
- 选中对象后的三轴变换/可视化 gizmo；
- 浮动属性面板；
- 选择范围高亮和非模态编辑；
- 大量操作使用快捷键和可回退操作；
- 视口中直接操纵对象，而不是全部依赖数字输入。

## 特效编辑 UI 结构

当前 RhythmcMaker 已注册“特效轨道”物品，但 RhythmcMakerClient 仍将其打开为 PlaceholderScreen("特效轨道", "effect-track")。因此建议先替换这一入口，不要另起一套无关联菜单。

推荐布局：

`	ext
┌──────────────────────────────────────────────┐
│ 顶部：返回 | 播放/暂停 | 当前 beat/ms | 撤销重做 │
├────────────┬────────────────────┬────────────┤
│ 特效列表    │ 特效时间线/轨道      │ 属性检查器  │
│ 类型筛选    │ beat 网格、事件块     │ 类型/时间   │
│ 新建特效    │ 拖动、复制、对齐      │ properties  │
├────────────┴────────────────────┴────────────┤
│ 底部：缩放、吸附、BPM/小节标记、当前选中摘要       │
└──────────────────────────────────────────────┘
`

### 左侧特效列表

- 按 ffectType 分类；
- 显示当前谱面已有特效数量；
- 支持搜索和仅显示当前时间附近；
- 新建时选择 RhythMC 3.0 支持的类型：HOLOGRAM、TITLE、FIREWORK、TIME、EFFECT、CLEAR_EFFECT、WEATHER、ARENA、TEXT_DISPLAY、HIDE_NOTES、GLOW_COLOR、MESSAGE 等。

### 中央时间线

- 横轴权威使用 beat，不用渲染帧或整数 tick；
- 同时显示 beat、秒、毫秒；
- 小节线由 BPM 表计算；
- 点击时间线设置当前事件 beat；
- 拖动事件块改变 beat，并提供 snap 到 1/1、1/2、1/4、1/8、1/16；
- 支持框选、复制、删除、批量移动；
- 播放头与现有音频播放时钟共用，不另造 UI 时钟。

### 右侧属性检查器

不要直接显示原始 JSON 文本作为主要编辑方式，而应根据 effectType 生成表单：

- 通用：事件类型、beat、enabled、备注；
- 文本类：文本、颜色、字号、持续时间；
- 时间/天气类：时间值、天气类型；
- 药水效果：效果 ID、等级、持续时间；
- 音符显示类：颜色、目标范围、持续区间；
- Arena 类：场景名称、切换时间；
- 未知 properties：保留原始 JSON，并显示只读/高级编辑入口，避免导入后丢字段。

## 数据模型前置要求

当前 Maker 仍没有完整的 3.0 effect 模型，且 ChartManifest 主要保存扁平音符。正式做 UI 前必须先有：

`	ext
ChartDocument
├── metadata
├── bpmEvents
├── tracks
├── effects
└── sceneReference

EffectEvent
├── id
├── type
├── beat
├── properties (保留未知字段)
└── source/dirty metadata
`

所有编辑操作应走统一的命令/操作层：

`	ext
EffectCreate
EffectUpdate
EffectMove
EffectDelete
EffectDuplicate
`

这样才能支持撤销/重做、批量移动和导入未知字段透传。

## ImGui 与 owo-ui 的选择

### 一期建议：owo-ui 原生实现

优先用现有 owo-ui：

- 不增加原生库；
- 与当前 RhythmcScreen、Minecraft 输入焦点和中文字体更一致；
- 更容易维护和兼容无 Flashback/Axiom 环境；
- 适合表单、列表、属性面板和基础时间线。

### 二期可选：独立 ImGui 时间线层

仅当 owo-ui 无法满足高频拖拽/关键帧需求时，再单独引入 ImGui binding：

- 由 Maker 自己创建 ImGui context；
- 自己处理 Minecraft 鼠标/键盘捕获；
- 自己处理字体、缩放、窗口停靠和 GL 状态恢复；
- 明确 native DLL/SO 打包和平台支持；
- 与 Minecraft 原生 Screen 通过一个 EffectEditorOverlay 生命周期桥接。

不要直接复用 Flashback 的 CustomImGuiImpl*。

## 实施顺序

### Phase 1：效果数据和基础面板

- 定义 EffectEvent 和 properties 保留结构；
- 将 EFFECT_TRACK_ITEM 从 PlaceholderScreen 接入 EffectTrackScreen；
- 实现列表、创建、删除、属性表单、保存和撤销；
- 先支持 MESSAGE、TITLE、GLOW_COLOR、TIME 四种低风险效果。

### Phase 2：时间线

- 添加 beat 时间线、小节线和播放头；
- 实现拖动、snap、复制、批量移动；
- 与现有 BPM、offset 和播放时钟绑定；
- 支持循环预览和定位。

### Phase 3：复杂效果和场景

- 支持 TEXT_DISPLAY、ARENA、HIDE_NOTES、EFFECT、WEATHER、FIREWORK；
- 为场景/Arena 增加视口预览和属性检查器；
- 添加 Axiom 风格的选中高亮和 gizmo，但使用 Maker 自己的渲染器。

### Phase 4：高级 UI

- 可停靠窗口、快捷键、窗口布局保存；
- 必要时增加独立 ImGui 时间线；
- 加入“基础模式/高级 JSON 模式”切换。

## 给编译方的任务清单

1. 不把 Flashback/Axiom JAR 添加为 Maker 依赖。
2. 先检查/扩展 3.0 effect 数据模型，再实现 UI。
3. 替换 EFFECT_TRACK_ITEM 当前的 PlaceholderScreen 路径。
4. 以 owo-ui 实现第一版三栏特效编辑器。
5. 统一使用 beat 作为时间线数据，不把事件位置写死为毫秒或帧。
6. properties 采用可扩展 JSON 对象，未知字段必须保留。
7. 编辑操作接入统一 undo/redo 命令层。
8. 第二阶段再实现时间线拖拽和 snap，第三阶段再处理复杂场景特效。
9. 若采用 ImGui，使用独立明确授权的 binding，并记录 native 库与许可证。

## 验收标准

- 未安装 Flashback/Axiom 时，特效编辑器仍能正常打开。
- 打开“特效轨道”不再进入 PlaceholderScreen。
- 能创建、编辑、删除、复制至少四种基础效果。
- 拖动事件后 beat 值正确变化，播放头和音频时钟一致。
- 未知 properties 导入后再次保存不丢失。
- 撤销/重做覆盖新增、移动、修改和删除。
- UI 不修改音频 BPM/offset 的语义，也不把谱面偏移误当歌曲偏移。
