# 2026-10-17 轨道吸附 bug 修复（1.13.11）

## 模式
bug 修复。

## 修复内容
- 修正轨道布局重算时中心坐标与方块坐标混用的问题，布局从每 Chunk 分数 8 改为 16 后，整数 beat 不再写成小数 z。
- 吸附小数音符时生成新的 UUID 音符，并从谱面中移除旧音符；原有整数音符保持原 ID。
- 撤销改为异步场景操作，显示进度并复用编辑锁；恢复吸附前完整快照，只删除本次吸附生成的 UUID，不删除吸附前已有整数音符，也保留撤销期间用户新增的音符。
- 修改每 Chunk 分数后清理客户端刷新请求和吸附状态缓存，立即重新读取谱面文件并刷新按钮状态。
- 布局变化会失效服务端撤销状态并通知客户端，避免 UI 显示过期撤销按钮。
