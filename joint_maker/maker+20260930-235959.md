# UI 崩溃修复记录

- 时间：2026-09-30
- 版本：1.5.10
- 工程：F:\b晴天小雨awa\RhythMC\rhythmc maker

## 问题定位

实例日志 `latest.log` 在打开 `ChartListScreen` 后记录：

- `ImGui beginFrame reached: initialized=false`
- `Dear ImGui Assertion Failed: Could not load font file!`
- 调用链落在 `ImGuiRuntime.loadChineseFont(ImGuiRuntime.java:213)`。

这说明崩溃发生在 UI 首帧初始化加载 Misans 字体时，而不是谱面数据或服务端播放逻辑。此前的 `NoSuchMethodError` 和 `Can only blur once per frame` 属于旧日期的历史崩溃记录，本次 00:42 的最新日志实际指向字体加载失败。

## 修复

- `ImGuiRuntime` 改为读取字体字节并调用 `addFontFromMemoryTTF`，避免原生层重新打开字体文件失败。
- 保留 Misans 字体数据引用到 ImGui 生命周期结束，避免字体内存被提前回收。
- 字体被 ImGui 拒绝或读取异常时自动使用 ImGui 默认字体，不再让 UI 初始化停在原生断言处。
- UI 仍保持原有字体资源和中文 glyph 范围配置。
