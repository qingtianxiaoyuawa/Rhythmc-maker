# Fabric Language Kotlin 前置核对

## 结论

当前 Maker 的发布成品需要安装 **Fabric Language Kotlin**。这不是 Maker 顶层 `fabric.mod.json` 直接声明的依赖，而是随成品嵌套打包的 Arcade 模组声明了硬依赖，因此对整包而言仍是必需前置。

## 核对证据

- Maker 顶层 `fabric.mod.json` 的 `depends` 没有 `fabric-language-kotlin`。
- 成品 `build/libs/rhythmc-maker-2.0.0.jar` 中嵌套的 `arcade-dimensions`、`arcade-event-registry`、`arcade-events-server`、`arcade-extensions`、`arcade-utils` 均在各自 `fabric.mod.json` 的 `depends` 声明 `fabric-language-kotlin >=1.13.7+kotlin.2.2.21`。
- 主源码未发现 Kotlin/Kotlinx API 符号引用；构建配置中的 `modLocalRuntime files("libs/fabric-language-kotlin.jar")` 是开发运行配置。此点不改变发布成品内嵌 Arcade 子模组的硬依赖事实。
- 发布包中未把 Fabric Language Kotlin 作为 `META-INF/jars` 嵌套依赖打包；它应由玩家在实例中单独安装。

## 给用户的部署说明

在对应 Fabric 实例安装 Fabric Language Kotlin，且版本需满足嵌套 Arcade 模组元数据要求（最低 `1.13.7+kotlin.2.2.21`）。实际下载时选择与当前 Minecraft/Fabric 环境兼容的发行版本。否则 Fabric Loader 会因嵌套模组缺少依赖而阻止加载，Maker 内功能即使没有直接 Kotlin 调用也不能绕过该依赖检查。

## 范围与限制

本次只检查源码引用、Maker 元数据、当前本地成品顶层/嵌套元数据和构建依赖配置；未运行游戏或构建。发布包快照为 `rhythmc-maker-2.0.0.jar`。
