## 本轮检查与修复

1. 中文字体图集缺少 Latin/default glyph：修复为 default font + SimHei 中文 glyph 合并。
2. 字体未像素对齐：启用 PixelSnapH，降低小字号断裂。
3. ImGui GLFW backend 与 Minecraft 输入重复：移除 ImGuiImplGlfw 初始化和 newFrame。
4. Minecraft 滚轮与 ImGui 滚轮重复注入：保留单一路由 MouseMixin -> ImGuiIO。
5. 键盘释放状态缺失：BaseOwoScreen 增加 keyReleased 转发。
6. UI 坐标与 framebuffer 尺寸不一致：继续使用 scaled display size 与 framebuffer scale。
7. renderer 强制绑定 framebuffer 0：移除强制 glBindFramebuffer，使用 Minecraft 当前 framebuffer。
8. ImGui 外层窗口自身滚动：关闭外层 NoScrollbar/NoScrollWithMouse。
9. 外层 content child 再次滚动：关闭 content child 滚动，只允许业务滚动容器滚动。
10. 业务滚动容器 flags 不明确：仅对 scroll layout 添加 AlwaysVerticalScrollbar。
11. 无关 ImGui ini 布局残留：外层使用 NoSavedSettings。
12. 窗口尺寸固定边距造成裁剪：外层窗口改为 0,0 到全屏尺寸。
13. 旧界面层级延续：增加新的工作台外壳、顶部工具栏和统一暗色主题，业务组件逻辑保留。
14. 输入焦点键修饰键状态不完整：继续在 keyPressed/keyReleased 中同步 modifiers。
15. 多窗口/多 viewport 干扰：保持 ViewportsEnable 关闭。
16. GL 状态污染导致模糊/裁剪：保留 renderer 的状态备份恢复，并在当前 framebuffer 绘制。
17. 滚动条视觉重复：外层与 content child 不显示滚动条，只有显式 verticalScroll 组件显示。
18. 资源/打包遗漏：核验 JAR 内含 ImGui binding、LWJGL3、Windows natives、Mixin 配置和关键 class。
