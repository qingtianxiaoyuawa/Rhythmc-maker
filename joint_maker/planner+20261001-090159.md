# RhythMC Maker UI 改造方案总结

- 日期：2026-10-01
- 身份：Planner
- 本轮职责：总结已确认方案，不修改源码、不编译、不测试、不部署。

## 总体目标

RhythMC Maker 的 UI 分为两类处理：

1. **特效编辑器菜单**：借鉴 Flashback 的编辑器界面，进行结构和视觉重构，加入专用时间轴。
2. **其他菜单**：保留原有功能逻辑和数据行为，只重构视觉、布局和控件表现，不加入时间轴。

## 特效编辑器

特效编辑器使用独立的新界面，不以旧 Owo 页面结构为基础，布局为：

- 顶部：返回、保存、播放、撤销/重做、视图等操作。
- 中央：Minecraft 场景/特效预览。
- 右侧：当前特效事件的属性检查器。
- 底部：特效专用时间轴、Beat 标尺、播放头、事件轨道和缩放控制。

时间轴功能包括：

- 按 Beat 定位和编辑特效事件。
- 播放头移动、缩放、水平滚动。
- 事件选择、添加、拖动、复制、删除。
- 根据选中事件更新右侧属性。
- 长轨道按可见范围绘制，避免一次性创建全部 UI 对象。

时间轴只用于特效编辑器，不推广到谱面列表、场景设置、导入导出或其他菜单。

## 其他菜单

其他菜单必须继续保留原有逻辑，包括：

- 谱面创建、列表、信息、保存和导出。
- 谱面与场景导入。
- 场景编辑、重置、删除及确认流程。
- 播放设置、播放/暂停/停止和失败清理。
- 物品选择、文件选择、输入校验和错误提示。
- `.rmcc`、`.rmcd`、`.schem` 的文件语义。
- Beat、BPM 分段、offset、速度事件和音频同步规则。
- 原有菜单入口、返回、取消、确认和快捷键语义。

这些菜单只重构以下内容：

- 页面布局和空间分区。
- 字体、字号和文字层级。
- 颜色、边框、背景和高亮状态。
- 按钮、输入框、下拉框、复选框和滚动条样式。
- 控件间距、对齐方式和窗口自适应。
- 模态窗口和错误提示的视觉表现。

## 统一视觉方向

参考 Flashback 的简洁暗色编辑器风格，但不复制其源码或专有实现：

- 深灰/蓝灰背景。
- 低对比度面板和细分隔线。
- 紧凑但不拥挤的控件。
- 蓝色只用于选中、播放、拖动和主要操作。
- 减少大面积卡片、厚重边框和重复嵌套面板。
- 中文和英文使用统一字体体系。
- 每个页面只保留必要的滚动容器，避免多重滚动条。

## 旧 UI 的保留范围

不保留旧 UI 的以下部分：

- 旧页面布局。
- 旧的居中窄表单结构。
- 旧 FlowLayout/卡片组合。
- 旧控件外观和间距。
- 旧颜色、边框和视觉层级。
- 以 `BaseOwoScreen` 为核心的界面继承结构。

只保留经过确认仍有价值的业务逻辑、数据模型、文件格式、播放逻辑以及可独立复用的底层 ImGui/Minecraft 渲染和输入能力。

## Owo-lib 迁移路线

Owo 只允许在迁移期间短暂存在，最终完全移除：

1. 建立自有 ImGui Screen、主题、控件、布局、输入路由和模态窗口基础层。
2. 先迁移普通高频菜单，保持原业务逻辑不变。
3. 单独建立新的特效编辑器和时间轴，不复用旧 `EffectTrackScreen` 的布局或组件树。
4. 按菜单完成迁移后，删除对应旧 Owo Screen 和专用组件。
5. 迁移全部菜单后，删除 Owo 源码、`BaseOwoScreen` 判断、Owo 输入分支和旧 UI helper。
6. 最终生产源码不再包含 Owo 包名或类型引用。

新代码不得继续引入 Owo；迁移期也不把 Owo 作为最终备用界面。

## 实施顺序

1. 盘点旧菜单的业务动作、数据读写、校验和导航行为，不保留旧布局。
2. 建立统一视觉主题和自有 ImGui 普通菜单容器。
3. 选择一个普通菜单完成视觉重构，验证原功能逻辑不变。
4. 按菜单逐步迁移其他普通页面。
5. 独立实现特效编辑器、中央预览、右侧检查器和底部时间轴。
6. 接入现有特效数据、保存、播放和 Beat 时间映射逻辑。
7. 删除已迁移菜单的 Owo 代码和旧 UI 组件。
8. 全部迁移完成后清除剩余 Owo 依赖和旧 UI 入口。

## 验收标准

- 只有特效编辑器使用 Flashback 风格时间轴。
- 其他菜单保留原有功能逻辑，但视觉上不再拥挤、丑陋或使用旧卡片布局。
- 特效时间轴与预览、属性检查器、播放头和特效事件正确联动。
- 普通菜单不出现与自身职责无关的时间轴或复杂工作台元素。
- 文件格式、Beat/BPM/offset、播放、场景和导入导出逻辑保持兼容。
- 新代码不再新增 Owo 引用，最终工程删除 Owo UI 源码和相关输入耦合。
- 不同窗口尺寸和 GUI 缩放下无明显裁剪、重叠、双滚动条或布局失衡。

## 最终结论

最终方案是：**特效编辑器采用 Flashback 风格的专用时间轴界面；其他菜单保留原有逻辑，只进行视觉重构；旧 UI 的布局和外观原则上不保留；Owo 仅作为迁移过渡，最终完全移除。**
