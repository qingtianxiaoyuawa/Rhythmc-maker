# WorldEdit 音符高度规则修复

- 时间：2026-09-27 16:04:10
- 问题：WorldEdit 放置音符时，高度和方块类型校验的条件写反，导致合规组合被拒绝、错误组合可能被同步为音符。
- 根因：worldEditWriteTarget 使用了反向三元条件：y=65 时拒绝钻石块，y=66-68 时拒绝其他三种音符块。
- 修改：新增统一的 isAllowedNoteTypeAtHeight(y, type) 规则，并让普通放置和 WorldEdit 放置共用。
- 规则：y=65 仅允许钻石块；y=66 到 y=68 仅允许 TNT、侦测器和红石块；WorldEdit 的空气写入仍允许删除既有音符。
- 修改文件：src/main/java/cn/frkovo/rhythmcmaker/RhythmcMaker.java。
- 验证：gradle --offline compileJava --no-daemon 通过。
- 验证：gradle --offline build --no-daemon 通过；测试任务为 NO-SOURCE。
- 部署：uild/libs/rhythmc-maker-1.5.1.jar 已强制覆盖到 Rhythmc 3.0 mods 目录，构建和部署 SHA-256 均为 D0772ADF9476CF01812E988BAF59A0B546597DF1F2D61D4DCEA2F40B291246A9。
- 阻塞：旧 JAR 被运行中的游戏锁定，无法移动到 bak；需完整重启游戏才能加载本版本。
- 下一步：重启后使用 WorldEdit 分别测试 y=65 钻石块、y=66-68 的 TNT/侦测器/红石块，并确认其他高度组合被拒绝。
